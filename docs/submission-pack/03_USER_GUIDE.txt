3. GUEST — BROWSE THE WEBSITE
================================================================================

Without signing in you may:

  • View Home, Rooms, Room details, Dining info, Experiences, Gallery, Location, Contact
  • Browse amenities, policies, and published guest reviews on a room page
  • Open legal pages (privacy / terms) from the footer

Booking actions ask you to sign in first (you are returned to your booking after login).

Steps — explore rooms:
  1. Click Rooms in the top navigation (or use Home rooms carousel).
  2. Filter by price, bed type, or amenities if needed.
  3. Open a room card to see gallery, amenities, policies, reviews, and rates.

4. GUEST — CREATE ACCOUNT AND SIGN IN
================================================================================

Register:
  1. Go to /register.
  2. Enter name, email, password (and complete email OTP if the hotel enabled EmailJS).
  3. After success, you are a Guest user with a profile.

Sign in:
  1. Go to /login.
  2. Enter email + password.
  3. You land on the guest home (Your stay) or the page you were trying to book.

================================================================================
5. GUEST — SEARCH AND BOOK A ROOM
================================================================================

  1. On Home, use Check In / Check Out / Guests / Room type → Check Availability
     (or Book Now on a room).
  2. Pick nights inside the hotel’s open booking window. Past dates are blocked.
     Sold-out nights cannot be selected.
  3. Confirm room and guest counts on the booking flow.
  4. Submit the reservation (signed-in required).
  5. Note your confirmation code — desk and My bookings both use it.

8. GUEST — DINING AND ROOM CARE
================================================================================

These features unlock after the front desk checks you in (status checked_in).

Dining (website /dining):
  • Browse live menu
  • Place room-service style orders (charged to stay invoice as dining lines)
  • Request / manage table seating where offered
  • If not checked in, the page explains why ordering is closed

Room care (Your stay):
  • Request room cleaning (make-up)
  • Set Do not disturb (blocks new cleaning requests until cleared)
  • Watch status: requested → in progress → completed

9. RECEPTIONIST — FRONT DESK DAY
================================================================================

Login: desk@azurebay.test → Front desk tab.

Typical morning:
  1. Open Front desk — review arrivals (confirmed) and in-house stays.
  2. Search by guest name or confirmation code.
  3. Check in arriving guests (confirmed → checked_in).
  4. Open Details sheet for guest summary; Move dates if needed.
  5. At departure, Check out (frees the room for later dates).
  6. Mark No-show when a confirmed guest never arrives.
  7. Open Invoice — add charges, record payment, print or email bill.

Also use Guests tab for walk-in profiles; Services for guest requests queue.

11. MANAGER — INVENTORY, MEDIA, MENU, REVIEWS
================================================================================

Login: manager@azurebay.test

Overview:
  • Occupancy, revenue, feedback charts; export CSV
  • Guest reviews — Publish or Hide feedback for the public site

Inventory:
  1. Add Room type — name, nightly rate, bed, capacity, amenities chips, photo
  2. Add Physical rooms — room number, type, floor
  3. Edit / deactivate / restore types and rooms as needed
  Public /rooms updates from these types.

Media:
  • Name an image → Upload → later pick it in Inventory (no URL paste required)

Dining:
  • Full access: Menu CRUD + Reports + Kitchen + Tables

Housekeeping / Maintenance:
  • Assign tasks and tickets; oversee the floor

Managers cannot open Staff or Settings (admin only).

12. ADMIN — STAFF AND HOTEL SETTINGS
================================================================================

Login: admin@azurebay.test

Staff:
  1. Add staff — name, email, role (manager / receptionist / housekeeping / maintenance)
  2. System shows a one-time temporary password (Bay#…) — copy and share securely
  3. Use New password on a row to issue another temporary password
  4. Deactivate / Activate accounts (not the primary admin)

Settings:
  • Hotel name, currency, tax rate
  • Booking window (open from / open to) — guests can only book inside this range
  • Stay policies — add/edit/remove title+body rows shown on every room detail page
  • Save settings

Admin also has full operational tabs for oversight.

16. TROUBLESHOOTING
================================================================================

Problem: Website loads but rooms/booking fail
  → Confirm API is running on port 5000

Problem: “Sign in required” when booking
  → Expected — register/login, then continue

Problem: Cannot order dining
  → Ask desk to check you in first

Problem: Feedback not on Home page
  → Manager/Admin must Publish it under Overview → Guest reviews

Problem: House login fails / inactive
  → Use seed demo house@azurebay.test with AzureBay#2025; ask admin to Activate

Problem: Receptionist cannot edit menu
  → By design — ask a manager

Problem: Date not selectable
  → Outside booking window, past, or sold out
